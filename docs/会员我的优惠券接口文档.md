## 会员优惠券

### 我的优惠券-会员会员列表
**简要描述：**

- 展示当前会员已领取（兑换成功）的优惠券，以优惠券为主体，连表展示兑换该券所使用的票根记录。

**请求URL：**

- `POST /api/user/coupon/list`

**请求方式：**

- POST

**请求头：**

- 需携带会员 Token，字段名 `Token`（进行「会员登录」后签发）

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| page | 否 | int | 页码，从 1 开始，默认 1 |
| limit | 否 | int | 每页数量，默认 10 |
| order | 否 | string | 排序规则（预留，默认按兑换时间倒序） |

**请求示例：**

```json
{
  "page": 1,
  "limit": 10
}
```

**返回参数说明：**

`code` 为 200 表示成功；401 未登录；400 参数错误。

`data.list[]` = 优惠券对象 `coupon` + 兑换所用票根字段：

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| coupon.id | int64 | 优惠券 ID |
| coupon.shop_id | int64 | 所属店铺 ID |
| coupon.user_id | int64 | 发布该券的商户用户 ID |
| coupon.title | string | 优惠券标题 |
| coupon.categories | string | 多业态分类 ID 组合，如 `1,3,4` |
| coupon.coupon_type | int | 形式：`1`满减券 `2`折扣券 `3`首道门票折扣 `4`专属票价 |
| coupon.discount_amount | number | 优惠面额或折扣率 |
| coupon.min_point | number | 使用门槛金额，`0` 为无门槛 |
| coupon.total_count | int | 发放总数量 |
| coupon.receive_count | int | 已领取数量 |
| coupon.use_count | int | 已核销数量 |
| coupon.starttime | datetime | 生效时间 |
| coupon.endtime | datetime | 过期时间 |
| coupon.status | int | 状态：`1`正常发放中 `2`已抢光 `3`已下架/过期 |
| coupon.createtime | datetime | 创建时间 |
| coupon.updatetime | datetime | 更新时间 |
| ticket_id | int64 | 兑换所用票根主键 ID |
| channel_type | string | 渠道类型 |
| ticket_category | string | 票根分类 |
| template_id | int64 | 票根模板 ID |
| user_image_url | string | 票根图片地址 |
| ticket_title | string | 票根标题 |
| holder_name | string | 持票人姓名 |
| event_date | string | 使用日期 |
| seat | string | 座位信息 |
| ticket_amount | number | 票面金额 |
| is_handwritten | boolean | 是否手写票（0/1） |
| exchanged_at | datetime | 优惠券兑换时间 |
| data.total | int64 | 总数 |
| data.page | int | 当前页码 |
| data.limit | int | 每页数量 |

**备注：**

- 位于会员用户中心分组，受会员 JWT 鉴权保护
- 仅返回当前会员已兑换成功（`exchange_status=1` 且 `coupon_id>0`）的优惠券及其关联票根
- 默认按兑换时间 `exchanged_at` 倒序
