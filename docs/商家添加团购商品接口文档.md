## 商家团购商品

### 添加团购商品
**简要描述：**

- 商家新增团购商品（支持吃、住、行、游、购、娱六大业态），事务内同时保存产品主表、SKU 规格、明细清单、核销规则、票根联运优惠等附属数据。

**请求URL：**

- `POST /api/user/shop/goods/add`

**请求方式：**

- POST

**请求类型：**

- `application/json`

**请求头：**

- 需携带商家/店长登录 Token，字段名 `Token`

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| shop_id | 是 | int64 | 所属店铺/商家 ID |
| title | 是 | string | 产品标题，如：觉海听涛双人餐 / 双人观景房晚 |
| sub_title | 否 | string | 副标题/卖点宣导 |
| cover_image | 是 | string | 产品主图 URL |
| images | 否 | string | 轮播图 URL 数组，JSON 字符串，如 `["url1","url2"]` |
| biz_type | 是 | string | 业务类型：`EAT`-吃 `HOTEL`-住 `TRAVEL`-行 `TOUR`-游 `SHOP`-购 `FUN`-娱 |
| product_type | 是 | string | 产品形态：`SET_MEAL`-套餐 `VOUCHER`-代金券 `ROOM_NIGHT`-房晚 `TICKET`-门票 `TRANSFER`-接送机 `RENTAL`-租车 |
| original_price | 是 | number | 划线原价 |
| selling_price | 是 | number | 售卖起始价/团购价 |
| stock_type | 否 | int | 库存机制：`1`-总库存机制（默认）`2`-每日/场次动态库存 |
| total_stock | 是 | int | 总库存量 |
| valid_type | 否 | int | 有效期类型：`1`-指定时间段（默认）`2`-购买后X天内有效 |
| valid_days | 否 | int | 购买后有效天数（valid_type=2 时生效） |
| valid_start | 否 | string | 有效期开始时间，格式 `YYYY-MM-DD HH:mm:ss` |
| valid_end | 否 | string | 有效期结束时间，格式 `YYYY-MM-DD HH:mm:ss` |
| skus | 否 | array\<Object\> | SKU 规格列表 |
| items | 否 | array\<Object\> | 产品明细清单（套餐菜品/门票项目/赠送权益） |
| rule | 否 | Object | 核销/使用规则 |
| ticket_discount | 否 | Object | 票根识别联动优惠配置 |

**skus[].Object 参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| sku_name | 是 | string | SKU 规格名称，如：双人豪华餐 / 大床房(含双早) |
| original_price | 是 | number | 该规格划线原价 |
| price | 是 | number | 该规格实际售卖价 |
| stock | 是 | int | 该 SKU 剩余库存 |
| sku_code | 否 | string | 商家内部/第三方 SKU 编码 |
| spec_data | 否 | string | 扩展属性 JSON，如 `{"bed_type":"大床","breakfast":"双早"}` |

**items[].Object 参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| group_name | 是 | string | 分组类别，如：热菜/主食/赠送项目/费用包含 |
| item_name | 是 | string | 细项名称，如：清蒸石斑鱼/景区门票/延迟退房 |
| quantity | 否 | int | 数量，默认 1 |
| unit | 否 | string | 单位：份/张/位/次，默认 `份` |
| price | 否 | number | 单品参考价值/价值额 |
| is_choice | 否 | int | 是否多选一：`0`-必选项（默认）`1`-多选一选项 |
| choice_group_id | 否 | int | 多选一组 ID，用于前端同组可选选项分组 |

**rule.Object 参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| need_appointment | 否 | int | 预约规则：`0`-免预约（默认）`1`-需提前预约 `2`-指定场次/日期使用 |
| appointment_advance_hours | 否 | int | 需提前多少小时预约（24 代表提前1天），默认 0 |
| need_real_name | 否 | int | 是否需要出行人实名：`0`-不需要（默认）`1`-需要 |
| appointment_phone | 否 | string | 商家预约/咨询电话 |
| limit_per_user | 否 | int | 单用户限购张数，0 为不限 |
| limit_per_order | 否 | int | 单次下单/单桌限用张数，0 为不限 |
| usable_times | 否 | string | 每周可用时段 JSON，如 `[{"weeks":[1,2],"start":"11:00","end":"21:00"}]` |
| unusable_dates | 否 | string | 不可用日期 JSON 数组，如 `["2026-10-01","2026-10-02"]` |
| use_instructions | 否 | string | 使用须知文本数组 JSON，如 `["仅限堂食","不与店内其他优惠同享"]` |
| refund_rule | 否 | int | 退改规则：`1`-随时退/过期自动退（默认）`2`-条件退 `3`-不可退 |
| refund_advance_hours | 否 | int | 条件退款需提前的小时数，默认 0 |

**ticket_discount.Object 参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| is_enabled | 否 | int | 是否开启票根专属优惠：`0`-关闭（默认）`1`-开启；为 0 时不保存 |
| allow_ticket_categories | 否 | string | 支持的票种分类，多选逗号分隔，如 `火车票,飞机票,景区门票` |
| match_destination_city | 否 | string | 限定到达城市，如限制为 `杭州` 到达票 |
| discount_type | 否 | int | 优惠类型：`1`-凭票立减固定金额（默认）`2`-凭票打折 |
| discount_value | 否 | number | 优惠数值：立减金额(元) 或 折扣率(如 0.85 代表 85折) |
| ticket_valid_days | 否 | int | 票根时效要求：仅限票面时间近 X 天内，默认 3 |

**返回示例：**

```json
{
  "code": 200,
  "message": "添加团购商品成功",
  "data": {
    "product_id": 55
  }
}
```

**返回参数说明：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| code | int | 状态码：200 成功；401 未登录；400 参数错误；500 添加失败 |
| message | string | 提示信息 |
| data.product_id | int64 | 新创建的团购商品主键 ID |

**备注：**

- 接口属于商家应用，需商家/店长 Token（`/api/user` 分组）
- 新商品默认状态为 `1`-待审核，由后台审核后上架
- `sku`、`item`、`rule`、`ticket_discount` 均非必填，按需传参；`ticket_discount.is_enabled=0` 时该项不保存
- `images`、`spec_data`、`usable_times`、`unusable_dates`、`use_instructions` 为 JSON 字符串字段
- 注意：该 handler 当前尚未在路由文件中注册，上述路由地址为拟定值，需后端确认最终路径
