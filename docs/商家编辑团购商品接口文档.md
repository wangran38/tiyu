# 商家编辑团购商品接口文档

本文档包含两个接口：

| 接口 | 路径 | 用途 |
|:---|:---|:---|
| 商品详情（编辑回显） | `POST /api/user/shop/goods/detail` | 编辑页进入时拉取商品完整数据（主表 + 全部附表） |
| 编辑团购商品 | `POST /api/user/shop/goods/edit` | 提交编辑（主表更新 + 附表全量重建） |

## 一、商品详情（编辑回显）

**简要描述：**

- 商家获取自己商品的完整详情：主表 + SKU 规格 + 明细清单 + 核销规则 + 票根优惠，**专为编辑页回显设计**。
- 附表数据全部原样返回：即使票根优惠已关闭（`is_enabled=0`），也返回原配置供前端展示"已关闭"状态。
- 强制归属校验，只能查看自己名下的商品。

**请求URL：**

- `POST /api/user/shop/goods/detail`

**请求方式：**

- POST

**请求类型：**

- `application/json`

**请求头：**

- 需携带商家/店长登录 Token，字段名 `pgtoken`（也兼容 `Authorization: Bearer <token>`）

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| id | 是 | int64 | 商品 ID |
| shop_id | 否 | int64 | 店铺 ID；传了则一并校验归属，不匹配返回 403 |

**请求示例：**

```json
{ "id": 3, "shop_id": 1 }
```

## 二、商家编辑团购商品

**简要描述：**

- 商家/店长编辑自己发布的团购商品，事务化更新主表 + 全量重建 SKU 规格、明细清单、核销规则、票根优惠等附属数据。
- 强制校验商品归属（商品ID+店铺ID+商户用户ID 三者匹配），防止越权编辑他人商品。

**请求URL：**

- `POST /api/user/shop/goods/edit`

**请求方式：**

- POST

**请求类型：**

- `application/json`

**请求头：**

- 需携带商家/店长登录 Token，字段名 `pgtoken`（也兼容 `Authorization: Bearer <token>`）

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| id | 是 | int64 | 商品 ID（要编辑的目标商品） |
| shop_id | 是 | int64 | 所属店铺 ID（必须与商品归属一致） |
| title | 是 | string | 产品标题，如：觉海听涛双人餐 / 双人观景房晚 |
| sub_title | 否 | string | 副标题/卖点宣导 |
| cover_image | 是 | string | 产品主图 URL |
| images | 否 | string | 轮播图 URL 数组，JSON 字符串，如 `["url1","url2"]` |
| biz_type | 是 | string | 业务类型：`EAT`-吃 `HOTEL`-住 `TRAVEL`-行 `TOUR`-游 `SHOP`-购 `FUN`-娱 |
| product_type | 是 | string | 产品形态：`SET_MEAL`-套餐 `VOUCHER`-代金券 `ROOM_NIGHT`-房晚 `TICKET`-门票 `TRANSFER`-接送机 `RENTAL`-租车 |
| original_price | 是 | number | 划线原价 |
| selling_price | 是 | number | 售卖起始价/团购价 |
| stock_type | 否 | int | 库存机制：`1`-总库存机制（默认）`2`-每日/场次动态库存 |
| total_stock | 是 | int | 总库存量 |
| status | 否 | int | 商品状态：`0`-草稿 `1`-待审核 `2`-已上架 `3`-已下架；不传默认 0 |
| valid_type | 否 | int | 有效期类型：`1`-指定时间段（默认）`2`-购买后X天内有效 |
| valid_days | 否 | int | 购买后有效天数（valid_type=2 时生效） |
| valid_start | 否 | string | 有效期开始时间，格式 `YYYY-MM-DD HH:mm:ss` |
| valid_end | 否 | string | 有效期结束时间，格式 `YYYY-MM-DD HH:mm:ss` |
| skus | 否 | array\<Object\> | SKU 规格列表。**传 `null`/不传** 表示不动现有 SKU；**传 `[]`** 清空；**传值** 则全量重建（先删后插） |
| items | 否 | array\<Object\> | 产品明细清单。规则同 skus |
| rule | 否 | Object | 核销/使用规则。**传 `null`/不传** 表示不动；**传值** 则先删后插 |
| ticket_discount | 否 | Object | 票根识别联动优惠配置。**传 `null`/不传** 表示不动；**传值** 则先删后插（若 `is_enabled != 1` 则清空不重建） |
| calendar | 否 | array\<Object\> | 日历价库存（酒店/景区 `stock_type=2` 用）。**传 `null`/不传** 表示不动；**传 `[]`** 清空；**传值** 则全量重建 |

> 子对象字段（`skus[]`、`items[]`、`rule`、`ticket_discount`、`calendar[]`）定义与「添加团购商品接口」完全一致，详见 [商家添加团购商品接口文档.md](./商家添加团购商品接口文档.md)。编辑时子项的 `id` 字段会被忽略（强制自增），前端可传可不传。

**calendar[].Object 参数（日历价库存表）：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| sku_id | 否 | int64 | 关联 SKU ID，`0` 表示商品维度（无规格商品）；有规格商品按 SKU 分别设置 |
| date | 是 | string | 日期，格式 `YYYY-MM-DD`（如 `2026-10-01`） |
| price | 是 | number | 当日售价（元），如周末 598、平时 398 |
| stock | 是 | int | 当日库存 |
| status | 否 | int | `1`-可售（默认）`0`-停售/闭店/闭园 |

**返回参数说明：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| code | int | `200` 成功；`400` 参数错误；`401` 未登录/登录失效；`403` 越权；`404` 商品不存在；`500` 服务器错误 |
| message | string | 提示信息 |
| data.id | int64 | 编辑成功的商品 ID |
| data.updated | int64 | 主表更新影响行数（通常为 1） |

**前端接入提示：**

1. **回显流程**：商品列表 `POST /api/user/shop/goods/list` → 点击"编辑" → 调 `POST /api/user/shop/goods/detail` 拉取完整数据（含 skus/items/rule/ticket_discount）回填表单 → 用户修改后调本接口提交。
2. **子表编辑语义**（关键）：
   - 不传 `skus`/`items`/`rule`/`ticket_discount` 字段 → 保留原数据不动；
   - 传 `null` 同上；
   - 传 `[]`（空数组）→ **清空**该子表所有记录；
   - 传值（非空数组/对象）→ **全量重建**（先删全部旧记录，再插新记录）。
   - 因此前端若只想改主表信息，请不要带 `skus`/`items`/`rule`/`ticket_discount` 字段；若要改 SKU，需把**完整的最终 SKU 列表**传过来（不是增量）。
3. **状态流转**：编辑后若将 `status` 改为 `1`（待审核），需等后台审核通过后才会变为 `2`（已上架）出现在公开列表 `/api/shop/goods` 中。
4. **主图/轮播图**：建议先用 `/api/upload` 上传图片拿到 URL，再填入 `cover_image`/`images` 字段。
5. **有效期**：`valid_type=1` 时展示 `valid_start`/`valid_end`；`valid_type=2` 时展示 `valid_days`，二者在前端切换时建议互斥清空对方字段。

**错误示例：**

```json
// 未登录 / Token 失效（HTTP 401）
{ "code": 401, "message": "请先登录 (未检测到 pgtoken)" }

// 参数错误（缺必填字段）
{ "code": 400, "message": "参数错误", "data": "Key: 'id' Error:Field validation for 'id' failed on the 'required' tag" }

// 越权：商品不属于当前商户
{ "code": 403, "message": "无权编辑该商品：商品不存在或不属于当前商户" }

// 商品不存在
{ "code": 404, "message": "商品不存在或未变更" }

// 服务器错误（如事务回滚）
{ "code": 500, "message": "编辑团购商品失败", "data": "具体错误信息" }
```
