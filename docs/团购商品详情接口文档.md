# 团购商品详情接口文档

本文档包含两个商品详情接口，注意区分使用场景：

| 接口 | 路径 | 鉴权 | 使用场景 | 可见范围 |
|:---|:---|:---|:---|:---|
| 公开商品详情 | `GET/POST /api/shop/goods/detail` | 无需登录 | C 端商品详情页（下单前浏览） | 仅已上架商品，SKU 仅启用规格，票根优惠仅已开启，附商家摘要 |
| 商家编辑回显详情 | `POST /api/user/shop/goods/detail` | 需登录（pgtoken） | 商家编辑页进入时回填表单 | 自己名下全部状态商品，附表原样返回（含禁用 SKU、已关闭票根优惠） |

> 商家编辑回显详情的完整文档见 [商家编辑团购商品接口文档.md](./商家编辑团购商品接口文档.md) 第一章。

## 一、公开的团购商品详情

**简要描述：**

- C 端用户/游客查看团购商品完整详情：主表 + SKU 规格 + 明细清单 + 核销规则 + 票根优惠 + 商家摘要，**无需登录**。
- 只返回 `status=2`（已上架）的商品，草稿/待审核/已下架商品不可见。
- 公开视角过滤：SKU 只含启用（`status=1`）规格；票根优惠只返回已开启（`is_enabled=1`）的配置。
- 商家摘要不含佣金/手续费/负责人联系方式等敏感经营数据。

**请求URL：**

- `GET /api/shop/goods/detail` 或 `POST /api/shop/goods/detail`

**请求方式：**

- GET / POST

**请求类型：**

- GET 用 Query 参数；POST 用 `application/json`

**请求头：**

- 无需携带 Token

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| id | 是 | int64 | 商品 ID |

**请求示例：**

```
GET /api/shop/goods/detail?id=3
```

```json
// POST /api/shop/goods/detail
{ "id": 3 }
```

**返回参数说明：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| data.product | Object | 商品主表完整字段（字段表见列表接口文档） |
| data.skus | array | **启用的** SKU 规格列表，无则为 `[]`；用于规格选择器 |
| data.items | array | 套餐明细清单，按 `group_name` 分组渲染，无则为 `[]` |
| data.rule | Object/null | 核销/使用规则，未配置为 `null`；用于「购买须知」区块 |
| data.ticket_discount | Object/null | **已开启的**票根优惠配置，未开启/未配置为 `null`；用于票根优惠提示条 |
| data.calendar | array | 日历价库存（`stock_type=2` 时用），按 `date` 升序；用于 C 端日历选日期下单 |
| data.shop | Object/null | 商家摘要；商家不可见状态（待审核/冻结/驳回）时为 `null` |

**data.shop 字段说明：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| id | int64 | 商家 ID，用于跳转商家主页（`/api/shop/detail`） |
| name | string | 门店名称 |
| logo | string | 门店 Logo URL |
| status | int8 | `1`-营业中 `2`-休息中 |
| address | string | 详细地址 |
| longitude / latitude | number | 经纬度，用于地图组件 |
| opening_hours | string | 营业时间 |
| service_phone | string | 客服电话 |
| avg_cost | number | 人均消费（元） |

> `skus[]`/`items[]`/`rule`/`ticket_discount` 的字段定义与「添加团购商品接口」一致，字段表见 [商家添加团购商品接口文档.md](./商家添加团购商品接口文档.md)。

**前端接入提示：**

1. **页面组装**：轮播图（`images` JSON.parse，降级用 `cover_image`）→ 标题价格区（划线价 `original_price` + 团购价 `selling_price` + 已售 `sales_count`）→ 规格选择（`skus`）→ 套餐明细（`items` 按 `group_name` 分组）→ 购买须知（`rule` + `use_instructions` JSON.parse）→ 票根优惠条（`ticket_discount` 非 null 时展示）→ 商家卡片（`shop`，点击跳 `/api/shop/detail`）。
2. **有效期展示**：`valid_type=1` 显示 `valid_start` ~ `valid_end`；`valid_type=2` 显示"购买后 X 天内有效"。
3. **限购提示**：`rule.limit_per_user > 0` 时展示"每人限购 X 张"；`rule.limit_per_order > 0` 时展示"单次限用 X 张"。
4. **库存判断**：`stock_type=1` 用 `total_stock` 判断售罄；`stock_type=2`（每日动态库存）以 `calendar[].stock` 为准（按选中日期匹配）。
5. **票根优惠**：`discount_type=1` 立减 `discount_value` 元；`discount_type=2` 打折（如 `0.85` 表示 85 折）。

**错误示例：**

```json
// 缺少 id
{ "code": 400, "message": "参数错误：id 必填", "data": "具体原因" }

// 商品不存在 / 未上架 / 已下架
{ "code": 404, "message": "商品不存在或已下架" }
```

## 二、商家编辑回显详情（对比说明）

| 差异点 | 公开接口（本文档一） | 商家回显接口 |
|:---|:---|:---|
| 路径 | `/api/shop/goods/detail` | `/api/user/shop/goods/detail` |
| 鉴权 | 无 | pgtoken 登录 + 归属校验 |
| 商品可见状态 | 仅 `status=2` | 全部状态（含草稿/待审核/已下架） |
| SKU | 仅启用 `status=1` | **原样返回**（含禁用） |
| 票根优惠 | 仅已开启 `is_enabled=1` | **原样返回**（含已关闭配置） |
| 商家摘要 | 附带（`shop` 字段） | 不附带（商家就是自己） |
| 用途 | C 端商品页 | 编辑表单回填 |

完整参数与返回说明见 [商家编辑团购商品接口文档.md](./商家编辑团购商品接口文档.md) 第一章。
