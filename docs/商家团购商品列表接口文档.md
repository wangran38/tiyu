# 商家团购商品列表接口文档

本文档包含两个列表接口：

| 接口 | 路径 | 鉴权 | 可见范围 |
|:---|:---|:---|:---|
| 商家自查商品列表 | `POST /api/user/shop/goods/list` | 需登录（pgtoken） | 自己名下全部状态商品 |
| 公开商家商品列表 | `GET/POST /api/shop/goods` | 无需登录 | 指定商家的已上架商品 |

## 一、商家查看自己的团购商品列表

**简要描述：**

- 商家/店长查看自己发布的全部团购商品（含草稿、待审核、已上架、已下架），支持按店铺、状态、标题关键词筛选与分页。
- 强制按当前登录商户 `user_id` 过滤，无法查看他人商品。

**请求URL：**

- `POST /api/user/shop/goods/list`

**请求方式：**

- POST

**请求类型：**

- `application/json`

**请求头：**

- 需携带商家/店长登录 Token，字段名 `pgtoken`（也兼容 `Authorization: Bearer <token>`）

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| shop_id | 否 | int64 | 指定店铺 ID；不传则查该商户名下全部店铺的商品 |
| status | 否 | int | 商品状态筛选：`0`-全部（默认）`1`-待审核 `2`-已上架 `3`-已下架 |
| title | 否 | string | 标题关键词，模糊匹配 |
| limit | 否 | int | 每页条数，默认 10 |
| page | 否 | int | 页码，默认 1 |
| order | 否 | string | 排序方式，默认 `id DESC`（最新在前）；常用：`sales_count DESC`（销量优先）、`selling_price ASC`（价格升序）、`selling_price DESC`（价格降序） |

**请求示例：**

```json
{
  "shop_id": 1,
  "status": 0,
  "title": "",
  "limit": 10,
  "page": 1
}
```

**返回示例：**

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "list": [
      {
        "id": 3,
        "shop_id": 1,
        "user_id": 5,
        "title": "觉海听涛双人套餐",
        "sub_title": "含双早+延迟退房",
        "cover_image": "https://cdn.example.com/cover.jpg",
        "images": "[\"https://cdn.example.com/1.jpg\",\"https://cdn.example.com/2.jpg\"]",
        "biz_type": "EAT",
        "product_type": "SET_MEAL",
        "original_price": 398,
        "selling_price": 268,
        "status": 2,
        "stock_type": 1,
        "total_stock": 100,
        "sales_count": 12,
        "valid_type": 1,
        "valid_start": "2026-09-01T00:00:00+08:00",
        "valid_end": "2026-12-31T00:00:00+08:00",
        "valid_days": 0,
        "createtime": "2026-09-08T11:20:33+08:00",
        "updatetime": "2026-09-09T09:15:02+08:00"
      }
    ],
    "total": 25
  }
}
```

**返回参数说明：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| code | int | `200` 成功；`400` 参数错误；`401` 未登录/登录失效；`500` 服务器错误 |
| message | string | 提示信息 |
| data.total | int64 | 符合筛选条件的商品总条数（用于分页计算） |
| data.list | array | 商品列表，按 order 排序 |

**data.list[] 单条字段：**

| 参数名 | 类型 | 说明 |
|:---|:---:|:---|
| id | int64 | 商品 ID |
| shop_id | int64 | 所属店铺 ID |
| user_id | int64 | 发布商户用户 ID |
| title | string | 商品标题 |
| sub_title | string | 副标题/卖点 |
| cover_image | string | 主图 URL |
| images | string | 轮播图 URL 数组（JSON 字符串，前端需 `JSON.parse`） |
| biz_type | string | 业态：`EAT`-吃 `HOTEL`-住 `TRAVEL`-行 `TOUR`-游 `SHOP`-购 `FUN`-娱 |
| product_type | string | 形态：`SET_MEAL`-套餐 `VOUCHER`-代金券 `ROOM_NIGHT`-房晚 `TICKET`-门票 `TRANSFER`-接送机 `RENTAL`-租车 |
| original_price | number | 划线原价 |
| selling_price | number | 团购价 |
| status | int | `0`-草稿 `1`-待审核 `2`-已上架 `3`-已下架 |
| stock_type | int | `1`-总库存 `2`-每日/场次动态库存 |
| total_stock | int | 总库存 |
| sales_count | int | 已售数量 |
| valid_type | int | `1`-指定时间段 `2`-购买后X天内有效 |
| valid_start | string | 有效期开始（valid_type=1 时展示） |
| valid_end | string | 有效期结束（valid_type=1 时展示） |
| valid_days | int | 购买后有效天数（valid_type=2 时展示） |
| createtime | string | 创建时间 |
| updatetime | string | 更新时间 |

**前端接入提示：**

1. 列表页请求需在 Header 携带 `pgtoken`（登录后由 `/api/user` 相关登录接口返回）。
2. 分页：`total` 与 `limit` 配合计算总页数；上拉加载时递增 `page`。
3. 商品状态标签映射建议：`0`→草稿(灰) `1`→待审核(橙) `2`→已上架(绿) `3`→已下架(红)。
4. `images` 为 JSON 字符串，渲染轮播前先 `JSON.parse`，解析失败时降级为只显示 `cover_image`。
5. 新增商品入口对接 `POST /api/user/shop/goods/add`（参数详见《商家添加团购商品接口文档》），添加成功后刷新本列表。

**错误示例：**

```json
// 未登录 / Token 失效（HTTP 401）
{ "code": 401, "message": "请先登录 (未检测到 pgtoken)" }

// 参数错误
{ "code": 400, "message": "参数错误", "data": "具体原因" }
```

## 二、公开的商家商品列表（按商家ID）

**简要描述：**

- C 端用户/游客根据商家 ID 查看该商家**已上架**的团购商品列表，无需登录。
- 只返回 `status=2`（已上架）的商品，草稿、待审核、已下架的商品不可见。

**请求URL：**

- `GET /api/shop/goods` 或 `POST /api/shop/goods`

**请求方式：**

- GET / POST

**请求类型：**

- GET 用 Query 参数；POST 用 `application/json`

**请求头：**

- 无需携带 Token

**参数：**

| 参数名 | 必选 | 类型 | 说明 |
|:---|:---:|:---:|:---|
| shop_id | 是 | int64 | 商家/店铺 ID |
| biz_type | 否 | string | 业态筛选：`EAT`-吃 `HOTEL`-住 `TRAVEL`-行 `TOUR`-游 `SHOP`-购 `FUN`-娱 |
| product_type | 否 | string | 形态筛选：`SET_MEAL`-套餐 `VOUCHER`-代金券 `ROOM_NIGHT`-房晚 `TICKET`-门票 `TRANSFER`-接送机 `RENTAL`-租车 |
| keyword | 否 | string | 标题关键词，模糊匹配 |
| limit | 否 | int | 每页条数，默认 10 |
| page | 否 | int | 页码，默认 1 |
| order | 否 | string | 排序方式，默认 `id DESC`；常用：`sales_count DESC`（销量优先）、`selling_price ASC`（价格升序）、`selling_price DESC`（价格降序） |

**请求示例：**

```json
// POST /api/shop/goods
{
  "shop_id": 1,
  "biz_type": "EAT",
  "limit": 10,
  "page": 1
}
```

```
// GET /api/shop/goods?shop_id=1&biz_type=EAT&page=1&limit=10
```

**返回示例：**

```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "list": [
      {
        "id": 3,
        "shop_id": 1,
        "user_id": 5,
        "title": "觉海听涛双人套餐",
        "sub_title": "含双早+延迟退房",
        "cover_image": "https://cdn.example.com/cover.jpg",
        "images": "[\"https://cdn.example.com/1.jpg\",\"https://cdn.example.com/2.jpg\"]",
        "biz_type": "EAT",
        "product_type": "SET_MEAL",
        "original_price": 398,
        "selling_price": 268,
        "status": 2,
        "stock_type": 1,
        "total_stock": 100,
        "sales_count": 12,
        "valid_type": 1,
        "valid_start": "2026-09-01T00:00:00+08:00",
        "valid_end": "2026-12-31T00:00:00+08:00",
        "valid_days": 0,
        "createtime": "2026-09-08T11:20:33+08:00",
        "updatetime": "2026-09-09T09:15:02+08:00"
      }
    ],
    "total": 8
  }
}
```

**返回字段说明：**

- `data.list[]` 字段与接口一完全一致（见前文字段表），区别仅在于本接口固定只返回 `status=2` 的记录。
- `data.total` 为该商家符合条件的已上架商品总数。

**前端接入提示：**

1. 适用场景：商家主页/店铺详情页的「团购商品」Tab、扫码进店的商品橱窗。
2. 建议与 `POST /api/shops`（商家列表）或商家详情接口配合，先拿商家 ID 再加载商品。
3. 业态 Tab 筛选直接切换 `biz_type` 参数重新请求即可。
4. `images` 为 JSON 字符串，渲染前先 `JSON.parse`，失败降级只显示 `cover_image`。

**错误示例：**

```json
// 缺少 shop_id
{ "code": 400, "message": "参数错误：shop_id 必填", "data": "具体原因" }
```
